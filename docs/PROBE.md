# D1 设备端观察构建

设备：用户提供 iPhone 15 Pro Max / iOS 17.0 / TrollStore。当前目标仍是完整去广告（含开屏）；r1/r2 不能提前结束视频。D1 是取得真实运行路径所需的观察构建，**不是第三版去广告包**。

D1 从原始解密 IPA 构建，保留原主程序代码段，不应用 r1/r2 的计时修改。它新增一个 dylib 加载命令、诊断库和 Info.plist 版本标识。图标名称为“汽水诊断D1”；库实际执行后，应用内出现蓝色“诊断 D1”按钮。

代码只记录页面/视图类名、主程序地址偏移、广告管理器方法调用和堆栈地址。不会读取或输出账号、歌曲、输入文字、请求 URL、请求体、响应体或 token。日志最多 500 行，保存在当前进程内，点击诊断按钮才写入本机临时文本文件并弹出系统分享菜单。程序不自动发送日志。

## 设备端操作

1. 用 TrollStore 覆盖安装 D1，彻底退出后重新打开“汽水诊断D1”。
2. 确认应用内有蓝色“诊断 D1”按钮。若没有，反馈“没有 D1 按钮”，先排查构建加载，不能继续假定补丁已经运行。
3. 复现一次开屏广告和“看视频全天免费听”入口，进入视频播放即可，不需要额外等待广告结束来取得页面日志。
4. 点击蓝色“诊断 D1”按钮，将 `Qishui-Probe-D1.txt` 存储到文件，再附到对话。若分享菜单没有出现或视频页面遮挡按钮，退出视频页后再点。
